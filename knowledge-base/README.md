# XiaoMCP Knowledge Base

Simpan referensi knowledge base di folder ini.

## Struktur
- `index.json` → daftar dokumen knowledge base
- file referensi → `.txt`, `.md`, `.pdf`

## Tambah dokumen via workflow knowledge-base-admin
Format pesan:

```text
tambah
id: uu-adminduk-2014
title: Peraturan Undang-Undang Adminduk THN 2014
path: uuadminduk2014.pdf
type: pdf
tags: adminduk, uu, 2014
```

## Query
Gunakan workflow `knowledge-base` untuk menanyakan isi dokumen yang sudah terdaftar.
